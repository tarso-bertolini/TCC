2. Source code (./src/)
--------------------------------------------------------------------------------

src/data_generator.py
    Synthetic microgrid telemetry generator. Produces 8760 hourly rows
    (1 year) following: PV diurnal bell curve with seasonal multiplier and
    stochastic cloud noise; bimodal Gaussian demand peaks at 8 AM and
    7 PM; Time-of-Use tariff with random spikes representing anomalous
    pricing events. RNG seeded at 42 for reproducibility. When invoked
    directly, writes microgrid_data.csv next to the file.

src/microgrid_env.py
    Custom Gymnasium environment (MicrogridEnv) implementing the MDP:
        state  = [SOC ratio, demand_kw, pv_kw, tariff_rate]
        action in {0 = Discharge, 1 = Idle, 2 = Charge}
        reward = -(energy cost) - (SOC degradation penalty)
    Battery: 10 kWh capacity, +/-2.5 kW per hourly step.

src/q_learning.py
    Tabular Q-Learning baseline. The continuous observation is discretised
    into 10x8x6x5 bins (SOC, demand, PV, tariff). Standalone CLI for
    development:
        python src/q_learning.py --data data/microgrid_data.csv \
            --output output --timesteps 50000 --seed 42

src/train.py
    Unified training entry point. Trains PPO, DQN, or Q-Learning and
    writes the model, training log, and run metadata into --output.
    Parameters:
        --algo {ppo, dqn, q_learning}  algorithm to train (required)
        --data PATH                    input dataset (auto-generated if
                                       missing) (required)
        --output DIR                   output root (required)
        --timesteps INT                training steps (default 50000)
        --seed INT                     random seed (default 42)
    Per-algorithm outputs:
        output/model/<algo>_policy.zip  PPO / DQN policies (SB3 zip)
        output/model/q_table.npy        Q-Learning Q-table
        output/model/q_table.json       Q-Learning hyperparameter meta
        output/model/<algo>_run.json    Run metadata (command line args)
        output/logs/<algo>_training.log Training transcript

src/test.py
    Evaluation entry point. Loads a trained policy, replays it on the
    held-out 18% test split, and writes metrics, per-step traces, and a
    consolidated test log. Parameters:
        --weights PATH    trained model file; algorithm inferred from name
        --datadir DIR     directory containing microgrid_data.csv
        --output DIR      directory for logs/, model/test.log, metrics
        --seed INT        random seed
    Per-algorithm outputs:
        output/model/<algo>_metrics.json  Evaluation metrics
        output/model/test.log             Consolidated evaluation log
        output/logs/<algo>_test_trace.csv Step-by-step action trace

src/quantize.py
    Exports the trained PPO policy to int8 TensorFlow Lite Micro and
    emits the C header consumed by the ESP32 firmware. Parameters:
        --weights PATH    trained PPO .zip
        --data PATH       microgrid_data.csv (used for the calibration
                          set during full-integer quantisation)
        --output DIR      output root
        --header PATH     target C header (default
                          esp32/include/ppo_model_data.h)
    Outputs:
        output/model/ppo_quantized.tflite
        esp32/include/ppo_model_data.h
        esp32/include/ppo_model_data.cc

src/train_benchmarks_legacy.py
    Early proof-of-concept benchmark used during the first weeks of the
    project. Superseded by src/train.py + src/test.py and kept only for
    archival reference.

scripts/generate_artifacts.py
    Regenerates the reproducible non-trained assets: the synthetic
    dataset and the two manuscript diagrams. Does NOT run training. Run
    with:
        python scripts/generate_artifacts.py

3. Input data (./data/)
--------------------------------------------------------------------------------

data/microgrid_data.csv
    Synthetic 8760-hour telemetry dataset produced by
    src/data_generator.py with seed=42. Columns:
        timestamp, pv_kw, demand_kw, tariff_rate
    Train/test split applied at runtime by src/train.py and src/test.py:
    first 82% for training (rows 0..7182), remaining 18% (1577 rows) for
    testing.

--------------------------------------------------------------------------------
4. Trained models and metrics (./output/model/)
--------------------------------------------------------------------------------

output/model/ppo_policy.zip
    Final trained PPO policy (Stable-Baselines3 zip: data + policy.pth +
    optimizer state + system_info.txt). Produced by:
        python src/train.py --algo ppo --data data/microgrid_data.csv \
            --output output --seed 42 --timesteps 50000

output/model/dqn_policy.zip
    Final trained DQN policy (same format as PPO). Produced by:
        python src/train.py --algo dqn --data data/microgrid_data.csv \
            --output output --seed 42 --timesteps 50000

output/model/q_table.npy
    Final tabular Q-Learning Q-table (shape 10x8x6x5x3, float32).
    Produced by:
        python src/train.py --algo q_learning \
            --data data/microgrid_data.csv \
            --output output --seed 42 --timesteps 50000

output/model/q_table.json
    Hyperparameter metadata that accompanies q_table.npy (alpha, gamma,
    epsilon_end, bin counts, tensor shape).

output/model/ppo_run.json,
output/model/dqn_run.json,
output/model/q_learning_run.json
    Per-run command-line metadata written by src/train.py
    (algo, data path, output dir, timesteps, seed, model_path).

output/model/ppo_metrics.json,
output/model/dqn_metrics.json,
output/model/q_learning_metrics.json
    Per-policy evaluation metrics written by src/test.py. Fields:
    algo, weights, seed, n_steps, total_reward, baseline_total_reward,
    cost_reduction_pct, mae_kw, rmse_kw, soc_violations,
    tariff_shock_recovery_steps, inference_latency_ms, peak_memory_kb,
    wall_time_seconds.

output/model/ppo_quantized.tflite
    Int8 TensorFlow Lite Micro model exported by src/quantize.py for
    deployment on the ESP32 firmware. Produced by:
        python src/quantize.py --weights output/model/ppo_policy.zip \
            --data data/microgrid_data.csv --output output \
            --header esp32/include/ppo_model_data.h

output/model/train.log
    Consolidated training summary: one line per algorithm with the
    timesteps, seed, wall time, and final mean episodic reward.

output/model/test.log
    Consolidated evaluation log: full key=value dump for each policy's
    metrics block, in the order PPO -> DQN -> Q-Learning.

5. Per-run logs and traces (./output/logs/)
--------------------------------------------------------------------------------

output/logs/ppo_training.log,
output/logs/dqn_training.log,
output/logs/q_learning_training.log
    Per-algorithm training transcripts as written by src/train.py.
    PPO and DQN use the standard Stable-Baselines3 verbose=0 dump
    (rollout / time / train tables every n_steps update); Q-Learning
    logs one line per 1000 steps with the current epsilon and the
    running episodic reward.

output/logs/ppo_test_trace.csv,
output/logs/dqn_test_trace.csv,
output/logs/q_learning_test_trace.csv
    Step-by-step evaluation trace produced by src/test.py over the 1577
    hourly steps of the held-out test split. Columns:
        step, action, reward, soc_kwh, demand_kw, pv_kw, tariff_rate

output/logs/benchmark.log
    Side-by-side benchmark table for the three algorithms (cost
    reduction, MAE, RMSE, latency, peak memory, tariff-shock recovery,
    SOC constraint violations). Source for Table II "Illustrative
    comparison among the evaluated RL models" in tcc.tex.

output/logs/esp32_serial.log
    Capture from `pio device monitor -b 115200` during the on-device
    validation run (2026-05-30). Includes boot info (model size, tensor
    arena, sensor / dispatch pin mapping), 1 Hz per-step dispatch
    decisions, mean / min / max inference latency, on-device policy
    agreement with the workstation reference, and SOC constraint
    violations. Source for Table V "Illustrative embedded benchmark for
    the quantized PPO policy on ESP32" in tcc.tex.

8. Edge firmware (./esp32/)
--------------------------------------------------------------------------------

esp32/platformio.ini
    PlatformIO configuration. Target: esp32dev (ESP32-WROOM-32).

esp32/src/main.cpp
    Edge control loop. Reads four ADC channels (SOC, demand, PV,
    tariff), runs policy inference at 1 Hz, and drives the
    charge / discharge GPIO pins (GPIO18 / GPIO19).

esp32/src/policy_inference.cpp
    TensorFlow Lite Micro interpreter wrapper. Performs float -> int8
    input quantisation and reports per-inference latency in
    microseconds.

esp32/include/policy_inference.h
    Public API of the policy wrapper.

esp32/include/ppo_model_data.h
esp32/include/ppo_model_data.cc
    Generated by src/quantize.py from output/model/ppo_quantized.tflite.
    Holds the int8 model byte array (g_ppo_model_data) linked into the
    firmware.

esp32/README.md
    Build / upload instructions for the firmware.

10. End-to-end reproduction
--------------------------------------------------------------------------------

Prerequisites: Python 3.10+ with the packages listed in requirements.txt.

    # 0. Install dependencies
    python -m pip install -r requirements.txt

    # 1. Regenerate the synthetic dataset (idempotent, seed=42)
    python scripts/generate_artifacts.py

    # 2. Train all three policies
    python src/train.py --algo ppo \
        --data data/microgrid_data.csv --output output \
        --seed 42 --timesteps 50000
    python src/train.py --algo dqn \
        --data data/microgrid_data.csv --output output \
        --seed 42 --timesteps 50000
    python src/train.py --algo q_learning \
        --data data/microgrid_data.csv --output output \
        --seed 42 --timesteps 50000

    # 3. Evaluate each policy on the held-out test split
    python src/test.py --weights output/model/ppo_policy.zip \
        --datadir data --output output --seed 42
    python src/test.py --weights output/model/dqn_policy.zip \
        --datadir data --output output --seed 42
    python src/test.py --weights output/model/q_table.npy \
        --datadir data --output output --seed 42

    # 4. Quantise PPO for the ESP32 firmware
    python src/quantize.py --weights output/model/ppo_policy.zip \
        --data data/microgrid_data.csv --output output \
        --header esp32/include/ppo_model_data.h

    # 5. Build / flash the firmware (requires PlatformIO)
    cd esp32 && pio run -e esp32dev -t upload && pio device monitor -b 115200
