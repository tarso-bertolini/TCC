# TCC -- RL-based Microgrid Optimisation on the Edge

Bachelor's thesis project for the **PUCPR Computer Science** program.

> Evaluating how Reinforcement Learning adapts to volatile tariffs and
> anomalies in microgrid optimization, with deployment on ESP32 edge devices.

## What's in this repository

| Path | Purpose |
|------|---------|
| `tcc.tex`, `bibtex.bib`, `oldarticle.tex` | Manuscript sources |
| `pipeline_diagram.png`, `architecture_diagram.png` | Diagrams referenced by the manuscript (regenerated by `scripts/generate_artifacts.py`) |
| `src/` | Training, evaluation, and quantisation Python scripts |
| `data/microgrid_data.csv` | Synthetic 8760-hour telemetry dataset (reproducible, seed=42) |
| `esp32/` | PlatformIO firmware for the ESP32 edge deployment |
| `frontend-app/` | Electron monitoring dashboard (development tool, not required for reproduction) |
| `scripts/generate_artifacts.py` | Regenerates the dataset and diagram PNGs |
| `readme.txt` | Authoritative artifact description used for evaluation |
| `requirements.txt` | Python dependency pins |

`output/` is **not** committed: it is the directory that `src/train.py`,
`src/test.py`, and `src/quantize.py` write into. Run them locally to populate
it.

## Reproducing the manuscript results

```bash
# 1. Install dependencies
python -m pip install -r requirements.txt

# 2. Regenerate the dataset and diagrams (idempotent, seed=42)
python scripts/generate_artifacts.py

# 3. Train all three policies (50k steps each)
python src/train.py --algo ppo        --data data/microgrid_data.csv --output output --seed 42 --timesteps 50000
python src/train.py --algo dqn        --data data/microgrid_data.csv --output output --seed 42 --timesteps 50000
python src/train.py --algo q_learning --data data/microgrid_data.csv --output output --seed 42 --timesteps 50000

# 4. Evaluate them on the held-out test split
python src/test.py --weights output/model/ppo_policy.zip --datadir data --output output --seed 42
python src/test.py --weights output/model/dqn_policy.zip --datadir data --output output --seed 42
python src/test.py --weights output/model/q_table.npy    --datadir data --output output --seed 42

# 5. Quantise PPO for the ESP32 firmware
python src/quantize.py --weights output/model/ppo_policy.zip \
    --data data/microgrid_data.csv --output output \
    --header esp32/include/ppo_model_data.h
```

For the firmware:

```bash
cd esp32
pio run -e esp32dev -t upload
pio device monitor -b 115200
```
